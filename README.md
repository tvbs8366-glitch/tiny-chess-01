A tiny chess engine in 4 KB of Python: a 0x88 board, alpha-beta search with a transposition table, quiescence search, MVV-LVA + killer + history move ordering and null-move pruning, under a fixed node budget per move. It plays the house gauntlet through the make.fun env. The readable source is chess.py; main.py is the same source packed with the kit's compress command.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
